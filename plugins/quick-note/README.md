# 速记本

文件与授权流程示例：把主面板输入或剪贴板内容追加到笔记文件。

## 它能回答的两个问题

**1. 插件能随便读写硬盘吗？** 不能。`ztools.fs.readText/writeText/list` 只允许访问
**用户经系统对话框授权过的范围**：插件先 `ztools.dialog.saveFile()` / `openFile()`
拿到路径，宿主才会把该路径纳入本插件的可访问范围。想绕过对话框直接读 `C:\` 会被拒绝。

**2. 高风险权限是什么体验？** `fs.read.any` / `fs.write.any` 属于高风险权限：
插件清单里声明后，**首次真正调用**时宿主会在主面板弹出一次确认框
（允许 / 本次允许 / 拒绝 / 永久拒绝）。用户拒绝时插件收到 `permissionDenied`，
本示例会把它打印在日志里而不是崩掉。

## 指令

| 主面板输入 | 行为 |
| --- | --- |
| `记一笔 …` | 进入并把输入文本填进"待写入内容" |
| `看笔记 …` | 进入并停在读取流程，点「读取内容」预览 |
| `剪贴板记一笔 …` | 进入并自动把剪贴板内容填进输入框 |

## 落盘位置

| 数据 | 位置 |
| --- | --- |
| 所选笔记文件路径 | `<数据目录>/plugins/com.example.quick-note/data/`（私有存储） |
| 笔记正文 | 你自己选的那个文件（示例默认 `notes.md`） |
| 授权记录 | `<数据目录>/plugin-permissions.json`（宿主侧，插件读不到也改不了） |

## 目录结构

```text
quick-note/
  plugin.json        3 个 over 指令 + 文件/对话框/剪贴板权限声明
  index.html         输入 / 文件 / 预览三段式界面
  main.js            先读后写追加、授权错误兜底、私有存储记忆
  styles.css         跟随宿主主题
  vendor/ztools-sdk/ 自带 SDK
  logo.png           图标
  CHANGELOG.md       版本记录（市场发布说明从这里取）
```
