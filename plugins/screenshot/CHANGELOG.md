# 更新日志

## 1.0.3

- 首次整合到插件中心仓库，使用 `logo.png` 作为插件图标。
- 悬停自动预选应用窗口，单击确认窗口；桌面空白处单击全屏，支持自由拖选。
- 支持矩形、椭圆、箭头、画笔、文字与马赛克标注；文字字号可调，输入预览跟随选中颜色。
- 支持复制、保存、钉在桌面、贴图移动与等比缩放。
- 贴图右键提供关闭、复制、保存、编辑；直接编辑贴图原图并原位重新钉住。
- 修复文字输入焦点丢失与贴图缩放边缘白线，调整工具栏图标。

部分能力需要包含近期截图改进的 ZTools-Tauri 宿主：窗口预选依赖截图返回的窗口边界；70px 原生右键菜单和透明窗口底色由宿主实现。
