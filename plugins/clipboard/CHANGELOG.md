# Changelog

## 1.0.2 - 2026-10-09

- 进入插件仓库：剪贴板历史查看器——文本 / 图片分类浏览、图片缩略图、单击粘贴、清空历史、
  搜索复用主面板输入框（插件页内不放输入框）。
- 顶部动作区改为「分类页签贴左 + 清空贴右」；列表隐藏滚动条（仍可滚动）；文本条目最多两行、
  超出省略；底栏右侧显示「可见条数 / 总数 条 · 监听中」。
- 插件名从「剪贴板历史」改为「剪贴板」（清单 `title` 与 feature `label`）。

## 1.0.0 - 2026-10-07

- 首个版本：宿主保留剪贴板原生能力（监视 / 去重 / 裁剪 / 粘贴注入 / `CF_DIB → PNG`），
  插件只做界面，经 `@ztools/sdk` 的 `ztools.clipboard.*` 调用（`clipboard.read` / `clipboard.write`）。
